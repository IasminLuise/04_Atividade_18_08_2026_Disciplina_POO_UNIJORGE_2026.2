Contexto:

Uma pequena loja deseja desenvolver um sistema simples para registrar os produtos vendidos durante um determinado período. O funcionário precisa informar a quantidade de produtos vendidos e, em seguida, registrar o valor de cada venda.

Para evitar a repetição manual de comandos no programa, o sistema deverá utilizar uma estrutura de repetição for, permitindo executar uma determinada instrução várias vezes de forma controlada.

Problema proposto

Imagine que você foi contratado para desenvolver um programa que auxilie o funcionário da loja no registro das vendas realizadas durante o dia.

O programa deverá:

Perguntar quantas vendas serão registradas.
Utilizar a estrutura for para repetir o processo de entrada de dados.
Solicitar o valor de cada venda.
Calcular o valor total das vendas.
Apresentar, ao final, o total arrecadado.

Por exemplo:

===== REGISTRO DE VENDAS =====

Quantas vendas serão registradas? 5

Digite o valor da venda 1: R$ 25,00
Digite o valor da venda 2: R$ 40,00
Digite o valor da venda 3: R$ 15,00
Digite o valor da venda 4: R$ 32,00
Digite o valor da venda 5: R$ 18,00

Total de vendas: R$ 130,00
Desafio

O aluno deverá desenvolver o programa utilizando obrigatoriamente a estrutura for.

Como desafio adicional, o programa deverá informar:

a quantidade de vendas realizadas;
o valor total das vendas;
a média das vendas;
o maior valor de venda registrado;
o menor valor de venda registrado.
